## Deployment Notes

1. **GitHub Pages Settings:** Go to **Settings → Pages → Build and deployment**
2. **Source:** Select `Deploy from a branch`
3. **Branch:** `main` (or `master`)
4. **Folder:** `/ (root)`
5. **Save** — Your site will be live at `https://zencode22.github.io`
